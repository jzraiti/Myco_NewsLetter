## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, compact metadata separators |
| sm | 8px | Compact control spacing, stacked helper text |
| md | 16px | Default control padding, card body spacing, mobile gutter minimum |
| lg | 24px | Card sections, page intro spacing, pagination group spacing |
| xl | 32px | Major card padding, desktop form groups, section gaps |
| 2xl | 48px | Major section breaks, hero spacing, table/card separation |
| 3xl | 64px | Page-level vertical rhythm on desktop |

Exceptions: 44px minimum hit area for icon-only or compact tap targets; 48px minimum control height for primary mobile inputs and buttons.

Source: default contract, shaped by `07-CONTEXT.md` decisions D-03, D-10, D-13.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #111315 | Image scrims, page backplates, high-contrast reading surfaces |
| Secondary (30%) | #E8ECEF | Glass cards, nav/footer surfaces, table headers, muted support panels |
| Accent (10%) | #8FAF6B | Active nav state, current pagination chip, primary CTA fill, focused search field ring, key inline links |
| Destructive | #DC2626 | Unsubscribe confirmation and destructive feedback only |

Accent reserved for: primary subscribe CTA, current-page pagination state, active route indicator, focus ring on search/form controls, and high-priority inline links inside explanatory content. Do not use accent for all buttons, all borders, or decorative backgrounds.

Source: existing neutral token system from `globals.css` plus Phase 7 context decisions D-02, D-04, D-07, D-11; exact split and reserved-for list set as default for this phase.

## Visual Hierarchy

- Home: logo and display headline first, email capture second, trust/supporting feature cards third, subscriber-count proof last.
- Articles and newsletters: page title and intro first, search or page summary second, results container third, pagination controls last.
- JUFO: page title and explanatory framing first, search and result summary second, table container third, page navigation last.
- Shared nav/footer: keep route orientation and supporting links visually quieter than page content; active route gets the strongest nav cue.
- If any icon-only action is introduced in this phase, it must keep a 44px minimum hit area, an explicit `aria-label`, visible focus state, and either adjacent text or screen-reader-only text that names the action.

Source: `07-CONTEXT.md` decisions D-04, D-05, D-07, D-10, D-11.
